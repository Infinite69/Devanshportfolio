# Devansh Dubey - Official Portfolio

A premium, AI-enhanced portfolio website for Devansh Dubey, showcasing his skills, projects, and technical expertise.

## Features

- 🎨 **Modern Design**: State-of-the-art UI with dark/light mode support.
- 🧠 **AI Chatbot**: Integrated AI assistant powered by Google Gemini to answer questions about Devansh's profile.
- ⚡ **Blazing Fast**: Built with Vite, React, and TypeScript for optimal performance.
- 📱 **Fully Responsive**: Seamless experience across desktop, tablet, and mobile devices.
- 📝 **Project Showcases**: Detailed case studies of Devansh's work.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd devansh-dubey-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```
